YouTube Analytics プライバシーポリシー／利用規約
プライバシーポリシー
「Kino Analytics」（以下「本アプリ」）は、開発者本人が自身のYouTubeチャンネル運営の分析のために使用する個人用ツールです。
取得する情報
本アプリは、YouTube Analytics API および YouTube Data API v3 を通じて、利用者自身のYouTubeチャンネルの統計情報（再生回数、視聴時間、インプレッション、チャンネル登録者の増減など）を、読み取り専用で取得します。
利用目的
取得した情報は、利用者自身のチャンネル運営の分析にのみ使用します。
情報の保存と管理
取得した情報と認証情報は、利用者のパソコン内にのみ保存されます。
外部のサーバーへ情報を送信することはありません。
取得した情報を第三者に提供・販売することはありません。
お問い合わせ
本ポリシーに関するお問い合わせは、OAuth同意画面に表示されているサポートメールアドレスまでお願いします。
利用規約
本アプリは開発者本人の個人利用に限ります。
本アプリの利用にあたっては、YouTube および Google の利用規約・ポリシーに従います。
本アプリの利用により生じた損害について、開発者は責任を負いません。
